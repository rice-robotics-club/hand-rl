machine learning directory for ml related code (wrappers for different kinds of neural networks, nice API for initializing, querying, exporting, etc)


The structure of this will look something like:
1. an abstract base class for neural networks with common functionality
2. a concrete implementation of the abstract base class for a simple multi layer perceptron
3. a concrete implementation of the abstract base class for a recurrent neural network
4. a concrete implementation of the abstract base class for a convolutional neural network
